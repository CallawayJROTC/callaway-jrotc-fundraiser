# Callaway JROTC $10,000 Mission

This package is ready for GitHub Pages.

## Upload
Upload all files/folders in this package to your GitHub repository root.

## Update the amount raised
Open `script.js` and change:

```js
raisedAmount: 0
```

Example:
```js
raisedAmount: 2850
```

The percentage, progress bar, and remaining balance update automatically.

## Donation processing
All donation buttons and the QR code point to:

https://onlinedonations.us/home/tview_donate/8099

This website does not collect bank, card, or payment credentials.

## Fundraiser scope
The page intentionally does **not** state that donations fund uniforms.
Current funding uses include camps, competitions, travel, JLAB/academic opportunities,
college/career experiences, supplies, recognition, and training/program needs.

The included `images` folder already contains the cadet photos supplied for the website.
